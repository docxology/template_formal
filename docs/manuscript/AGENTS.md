# Manuscript guidance

Follow the [project contract](../../AGENTS.md) and
[rendering instructions](../rendering.md). Keep the numbered section order,
the Pandoc labels, and the source-owned [claim ledger](../../data/claim_ledger.yaml)
in sync. Claims about types, runtime guards, simulation, and formal side-specs
have distinct evidence and limits.

The source is rendered directly. Before changing a numerical claim, rerun its
cited test, analysis, or proof command from the [verification trail](../ISA.md#verification).
Add bibliographic entries to [references.bib](references.bib). For an analysis
figure, pair its source generator with a stable figure label and useful alt
text in the generated registry.
